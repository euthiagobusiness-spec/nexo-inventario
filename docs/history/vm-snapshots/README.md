# Variantes históricas recuperadas de las VMs

Estas copias fueron leídas durante la validación directa de las tres máquinas. Se guardan con extensión `.txt` para conservar el estado encontrado sin compilarlas ni reemplazar la aplicación TypeScript actual.

El [mapa de fuentes](../../../artifacts/github-vm-audit/historical-source-map.json) indica la VM/copia de origen, el archivo preservado y su SHA-256 normalizado. Las versiones ya presentes en `docs/history/` o `deploy/mysql/` se referencian y no se duplican.

La copia antigua `configure-database.py.txt` usa el nombre de configuración previo `inventario-private.cnf`. El configurador actual del repositorio y la instalación efectiva usan `zz-inventario-private.cnf`. Para instalación nueva seguir la documentación vigente.
